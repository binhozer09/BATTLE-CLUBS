# Mapas baixados

Coloque nesta pasta os arquivos dos mapas 3D que serão avaliados para o BATTLE CLUBS.

 formatos aceitos para análise: .fbx, .obj, .gltf, .glb, .dae, .blend, .unitypackage e arquivos compactados .zip/.rar.

Inclua também as pastas de texturas e materiais que acompanham cada mapa. Não substitua nem apague os assets existentes do projeto.
